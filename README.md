# Guia de instalacion de Vite + Sass

1. Instalar Node version LTS
2. npm create vite@latest sass-vite-template
3. cd sass-vite-template
4. npm i
5. npm i sass --save-dev
6. crear fichero de confirguracion vite.config.js para conseguir que los enlaces de los archivos sean relativos
